## Long Description (for About section / README)

```
🤖 LangChain Customer Support Agent

An educational project demonstrating how to build a production-ready customer support system using LangChain tools, OpenAI GPT-3.5, and Streamlit.

✨ Features:
- Automatic ticket classification (refund, technical, billing, general)
- AI-generated professional responses
- Refund request processing with order ID extraction
- Database integration (PostgreSQL/Supabase)
- Streamlit web interface
- Docker containerization
- AWS App Runner deployment ready

🛠️ Tech Stack:
- LangChain (tools, prompts, chains)
- OpenAI GPT-3.5
- Streamlit
- PostgreSQL/Supabase
- Docker
- AWS App Runner
- Python 3.10

📚 Perfect for:
- Learning LangChain fundamentals
- Understanding AI tool development
- Building your first AI application
- Production deployment examples

🚀 Quick Start:
1. Install: `uv pip install -e .`
2. Set OPENAI_API_KEY in .env
3. Run: `streamlit run app_langchain.py`

Built with ❤️ for learning and education.
```
